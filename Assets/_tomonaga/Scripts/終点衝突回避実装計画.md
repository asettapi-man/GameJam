# 終点衝突回避機能 実装計画

## 概要
終点（predictionPoint）が生成時に何かと衝突している場合、放物線の軌道に沿って始点方向へ戻し、衝突しない位置を見つけて再配置する機能を実装する。

---

## 現在の処理フロー
```
1. FlyingItem生成
   ↓
2. predictionPoint を固定距離に配置
   ↓
3. LineManager.SetFlyingPoints() で登録
   ↓
4. ParabolaLineRenderer.ActiveLine() で放物線描画
```

---

## 実装する処理フロー
```
1. FlyingItem生成
   ↓
2. predictionPoint を固定距離に配置
   ↓
3. LineManager.SetFlyingPoints() で登録
   ↓
4. ParabolaLineRenderer.ActiveLine() で放物線描画
   ↓
5. 【新規】終点の衝突判定を実行
   ↓
6. 【新規】衝突している場合：
      - 放物線の頂点配列を終点側から順にチェック
      - 衝突しない位置を発見
      - predictionPointをその位置に移動
      - 放物線を再描画
```

---

## 実装方針

### 1. 衝突検出の手段
Unity の物理衝突判定機能を使用：
- **Physics.OverlapSphere()**: 指定位置・半径内の全Colliderを取得
- **Physics.CheckSphere()**: 指定位置に衝突があるかBoolean判定（軽量）

推奨: `Physics.CheckSphere()` で効率的にチェック

### 2. 実装する場所
**ParabolaLineRenderer.cs** に新規メソッドを追加：
- `AdjustEndPointPosition()`: 終点の衝突回避処理

**呼び出しタイミング**:
- `ActiveLine()` 内で `DrawParabola()` の直後
- または `DrawParabola()` の最後に組み込む

### 3. アルゴリズム

```csharp
void AdjustEndPointPosition()
{
    // 終点の衝突判定用パラメータ
    float checkRadius = 0.5f;  // 衝突判定の半径

    // 終点が衝突していない場合は何もしない
    if (!Physics.CheckSphere(endPoint.position, checkRadius))
    {
        return;
    }

    // 放物線の頂点を終点側から逆順にチェック
    for (int i = segmentCount - 1; i >= 0; i--)
    {
        Vector3 candidatePos = line.GetPosition(i);

        // この位置で衝突判定
        if (!Physics.CheckSphere(candidatePos, checkRadius))
        {
            // 衝突しない位置を発見
            endPoint.position = candidatePos;

            // 放物線を再描画（終点が移動したため）
            DrawParabola();

            return;
        }
    }

    // すべての頂点で衝突している場合の処理
    Debug.LogWarning("放物線全体が衝突しています");
}
```

## 実装手順

### Step 1: ParabolaLineRenderer.cs に衝突検出メソッド追加
- `AdjustEndPointPosition()` メソッドを実装
- 衝突判定半径をインスペクタで調整可能にする（`public float collisionCheckRadius = 0.5f;`）

### Step 2: ActiveLine() に組み込み
```csharp
public void ActiveLine()
{
    // 放物線を描画
    DrawParabola();

    // 【新規】終点の衝突を回避
    AdjustEndPointPosition();

    // Particleを配置
    SpawnParticles();
}
```

### Step 3: デバッグ・調整
- 衝突判定の半径を調整
- LayerMask を使って特定レイヤーのみ判定対象にする
- Gizmos でデバッグ表示を追加

## 考慮事項

### A. LayerMask の使用
特定のレイヤー（例：壁、障害物）のみを判定対象にする：
```csharp
public LayerMask collisionLayers;  // インスペクタで設定

Physics.CheckSphere(position, radius, collisionLayers)
```

### B. 再帰的な放物線再描画
- `AdjustEndPointPosition()` 内で `DrawParabola()` を呼ぶと、終点位置が変わるため放物線が更新される
- 無限ループに注意（衝突判定後は必ずreturnする）

### C. パーティクル配置のタイミング
- `SpawnParticles()` は終点調整後に実行
- すでにパーティクルが存在する場合の処理（削除して再生成 or 位置更新）

### D. パフォーマンス最適化
- `Physics.CheckSphere()` は軽量だが、毎フレーム実行しない
- 終点生成時・マウスホイール移動時のみ実行

## 拡張案

### 1. スムーズな移動
終点を瞬間移動させず、Lerp で滑らかに移動：
```csharp
StartCoroutine(SmoothMoveEndPoint(newPosition));
```

### 2. ビジュアルフィードバック
- 衝突時に終点の色を変える
- 放物線の色を警告色に変更

### 3. 最小距離の保証
終点が始点に近すぎる場合の処理：
```csharp
if (Vector3.Distance(startPoint.position, candidatePos) < minDistance)
{
    continue;  // この位置はスキップ
}
```

## まとめ

**最小限の実装**:
1. `ParabolaLineRenderer.cs` に `AdjustEndPointPosition()` を追加
2. `ActiveLine()` から呼び出し
3. `Physics.CheckSphere()` で衝突判定
4. 放物線の頂点を逆順チェックして非衝突位置を発見

**メリット**:
- 既存コードへの影響が最小限
- 処理がシンプルで理解しやすい
- 放物線の自然な軌道を維持
